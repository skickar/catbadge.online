# Community firmware images

Merged ESP32-S3 badge factory images (`*.factory.bin`, flashable at `0x0`) submitted by the
community. Each file here has a matching entry in `../community.json` with its `sha256`.

**These are untested and unverified.** They are served to the Community BINs flasher, which warns
and gates every flash. Do not move anything here into the main `firmware/` catalog — that catalog
is for hardware-verified images only.

Add a file here only through the review flow in `../CONTRIBUTING.md` (a maintainer validates it with
the `catbadge-community-image` skill first).
